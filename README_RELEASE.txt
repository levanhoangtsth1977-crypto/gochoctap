GOCHOCTAP MASTER 2026 – RELEASE
Bản phát hành sau khi đã kiểm tra giao diện và các liên kết.

Cách triển khai GitHub Pages:
1. Giải nén toàn bộ gói này.
2. Đưa toàn bộ file/thư mục vào repository GitHub.
3. Đảm bảo index.html nằm ở thư mục gốc của repository (hoặc cấu hình Pages đúng thư mục chứa index.html).
4. Vào Settings > Pages và chọn Deploy from a branch.
5. Chọn branch chứa website và thư mục / (root), rồi Save.
